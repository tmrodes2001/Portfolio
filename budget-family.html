BudgetFamily

2026 | React • Supabase • Tailwind CSS

Private Project

A collaborative family budget management application where families can track expenses, manage members, and view financial analytics with role-based access control. Built with modern web technologies and security best practices.

Tech Stack

React 18 Vite Supabase PostgreSQL Tailwind CSS v4 Headless UI Context API JWT Auth

Key Features

  • Multi-user authentication with JWT tokens
  • Admin role system for family members
  • Row-Level Security policies for data protection
  • Real-time notifications
  • Transaction management and favorites
  • Dashboard with financial analytics
  • Responsive and accessible interface
